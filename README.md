# Тренажёр для запоминания ответов на тест

Веб-приложение для тренировки правильных ответов на основе базы вопросов из Excel-файла. Работает как в браузере на компьютере, так и на телефоне (можно установить как приложение — PWA).

## Возможности

- **Несколько областей аттестации в одном приложении** (сейчас Б.9.4 и А.1) — при запуске сначала выбирается область, дальше всё работает как обычно внутри неё; статистика, флажки «на повтор» и прогресс по каждой области считаются полностью независимо (кнопка «◀ Другая область» переключает контекст в любой момент, без потери прогресса ни в одной из областей).
- Три режима: по порядку, случайный, наиболее забываемые (приоритизация по количеству ошибок, недавним промахам и давности повтора — простой аналог интервального повторения).
- Фильтр по разделу базы (документ-первоисточник — набор доступных разделов свой для каждой области аттестации) — можно тренироваться по конкретному нормативному документу.
- Варианты ответов перемешиваются при каждом новом прохождении — чтобы не запоминалась позиция, а не суть.
- Статистика ответов с визуализацией последних 5 попыток по каждому вопросу (зелёные/красные квадраты).
- Отметка вопросов флажком «на повтор» — такие вопросы получают приоритет в режиме «Наиболее забываемые».
- Прогресс текущего прохождения сохраняется — можно закрыть вкладку и продолжить с того же места.
- Тёмная тема (переключается вручную, по умолчанию берётся из настроек системы).
- Адаптивный дизайн для мобильных устройств + PWA-манифест (кнопка «Добавить на экран «Домой»» на телефоне) + офлайн-кэш статики через service worker.
- **Синхронизация статистики между устройствами без ручного экспорта/импорта** — через Firebase (см. ниже). Без настройки Firebase приложение продолжает работать локально, в пределах одного устройства/браузера.

## Быстрый старт (просмотр в браузере)

Открытие `index.html` двойным кликом **не сработает** — браузеры блокируют `fetch()` локальных файлов по протоколу `file://`. Нужен любой локальный сервер или публичный хостинг.

Локально:
```
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Деплой на телефон и в браузер (GitHub Pages)

1. В репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
2. Через минуту приложение будет доступно по адресу вида `https://<ваш-логин>.github.io/PromBez_2026/` — эту ссылку можно открыть и на компьютере, и на телефоне.
3. На телефоне откройте ссылку в браузере → меню «Добавить на главный экран» — приложение появится как отдельная иконка и будет частично работать офлайн.

## Синхронизация статистики между устройствами (без ручного экспорта)

По умолчанию статистика хранится в `localStorage` — то есть **отдельно на каждом устройстве**. Чтобы прогресс автоматически подтягивался и на телефоне, и в браузере на компьютере без ручных действий при каждом использовании, приложение умеет синхронизироваться через **Firebase** (бесплатный тариф Spark, кредитная карта не требуется).

Настройка (разовая, ~5 минут):

1. Откройте <https://console.firebase.google.com>, создайте проект.
2. Project settings → General → Your apps → добавьте веб-приложение (`</>`), скопируйте объект конфигурации.
3. Build → Authentication → Sign-in method → включите **Google**.
4. Build → Firestore Database → Create database (production mode) → вкладка **Rules**, вставьте:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{userId} {
         allow read, write: if request.auth != null && request.auth.uid == userId;
       }
     }
   }
   ```
5. Вставьте скопированные значения в `firebase-config.js` (в репозитории).
6. Закоммитьте и задеплойте. На каждом устройстве один раз нажмите «🔗 Синхронизировать между устройствами» и войдите через Google — дальше статистика будет обновляться автоматически и в реальном времени на всех устройствах с этим аккаунтом, без каких-либо ручных действий по «отправить/загрузить».

> Значения в `firebase-config.js` — это публичная веб-конфигурация Firebase, а не секретные ключи. Безопасность обеспечивается правилами Firestore (шаг 4) — каждый пользователь видит и пишет только свой документ.

## Конвертация базы вопросов из Excel

Приложение поддерживает несколько областей аттестации в одном `data.json`. Конвертер принимает пары `<excel-файл> <название области>` — сколько угодно пар подряд, последним необязательным аргументом можно указать имя выходного файла (по умолчанию `data.json`):

```
pip install -r requirements.txt
python3 convert.py \
  testovaya_baza_198_s_otvetami.xlsx "Б.9.4" \
  testovaya_baza_A1_152_s_otvetami.xlsx "А.1" \
  data.json
```

Чтобы **добавить новую область аттестации** в будущем — просто добавьте ещё одну пару `<excel> <область>` в эту команду и пересоберите `data.json`; приложение подхватит её автоматически (новая кнопка на экране выбора области появится сама, без правок кода).

Однофайловый режим (одна область, по умолчанию «Б.9.4») остался для обратной совместимости:
```
python3 convert.py testovaya_baza_198_s_otvetami.xlsx data.json
```

Требования к каждому Excel-файлу: лист с базой вопросов, колонки `№ п/п`, `Тип`, `Текст вопроса`, `Вариант ответа 1..6`, `Нормативный документ, пункт`, `Текст пункта нормативного документа`, `Источник (страница)`. Правильный(-ые) вариант(-ы) отмечаются префиксом `[!]` прямо в тексте варианта — конвертер сам вырежет метку и вычислит индексы, отдельная колонка «Правильный ответ» используется только как сверка (при расхождении выводится предупреждение).

Идентификатор каждого вопроса в итоговом `data.json` глобально уникален и включает префикс области (например, `б94_1`, `а1_1`) — это и разводит статистику по областям (ключ статистики — id вопроса), и защищает от коллизий, если в разных базах номера вопросов совпадают.

После конвертации стоит прогнать проверку целостности:
```
python3 validate_data.py data.json
```
Скрипт проверяет уникальность id, наличие поля `examArea` у каждого вопроса и покажет сводку по количеству вопросов в каждой области.

## Структура репозитория

| Файл | Назначение |
|---|---|
| `index.html` | разметка |
| `style.css` | вся стилизация (без инлайн-стилей), тёмная тема, адаптив |
| `script.js` | логика приложения: режимы, статистика, синхронизация |
| `firebase-config.js` | конфигурация облачной синхронизации (см. выше) |
| `manifest.json`, `sw.js`, `icons/` | PWA — установка на телефон и офлайн-кэш |
| `data.json` | база вопросов по всем областям аттестации, сгенерированная из Excel-файлов |
| `convert.py` | конвертер Excel → JSON, поддерживает несколько областей аттестации за один запуск |
| `validate_data.py` | проверка целостности `data.json` перед коммитом |
| `testovaya_baza_198_s_otvetami.xlsx` | исходная база вопросов области Б.9.4 с обоснованиями |
| `testovaya_baza_A1_152_s_otvetami.xlsx` | исходная база вопросов области А.1 с обоснованиями |
