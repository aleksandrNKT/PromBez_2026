# Тренажер для запоминания ответов на тест

Веб-приложение для тренировки правильных ответов на основе базы вопросов из Excel-файла.  
Поддерживает одиночный и множественный выбор, показывает обоснование и ссылку на источник.

## 🚀 Быстрый старт

1. **Склонируйте репозиторий**
2. **Установите зависимости Python** (для конвертации Excel → JSON):
   ```bash
   pip install -r requirements.txt
