# Тренажер для запоминания ответов на тест

Веб-приложение для тренировки правильных ответов на основе базы вопросов из Excel-файла.

## Возможности
- Три режима: по порядку, случайный, наиболее забываемые (на основе статистики)
- Статистика ответов с сохранением в localStorage, отображаются все вопросы из базы
- Визуализация последних 5 ответов для каждого вопроса (зелёные/красные квадраты)
- Адаптивный дизайн для мобильных устройств

## Установка
1. Скопируйте файлы `index.html`, `style.css`, `script.js` в корень вашего сайта.
2. Поместите файл `data.json` с вопросами в ту же папку (или используйте встроенный пример).
3. Откройте `index.html` в браузере.
